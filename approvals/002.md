# Approval 002 — Full Disk Access for the shell so the ForgeOS loop can run under launchd

- **What:** Grant Full Disk Access to /bin/bash in System Settings → Privacy & Security → Full Disk Access, so the launchd agent com.hami.loop can execute the loop script from inside ~/Downloads/ForgeOS. This is a macOS system setting only Niroj can change in the GUI.
- **Why:** The loop currently lives in ~/pulsenp because macOS TCC blocks launchd from executing scripts inside ~/Downloads (proof: Downloads/ForgeOS/logs/launchd.err, "Operation not permitted", 5 respawns, no heartbeat ever written). The pulsenp loop works, but the ForgeOS location is the canonical home Niroj asked for. Granting Full Disk Access to /bin/bash would let the loop run from ForgeOS directly.
- **Decision needed (one word):** YES — Niroj grants Full Disk Access to /bin/bash / NO — the loop stays in ~/pulsenp
