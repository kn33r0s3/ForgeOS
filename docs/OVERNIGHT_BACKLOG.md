# Overnight backlog — superseded

BLOCKED labels are historical and are not a work queue or a statement of
current production state.

Use [SERIAL_PATH.md](SERIAL_PATH.md) as the only work order. For current
readiness and externally supplied evidence, use [CURRENT_FOCUS.md](CURRENT_FOCUS.md)
and [PUBLICITY_GATE.md](PUBLICITY_GATE.md). Reintroduce an item from older
reports only by adding it to the serial path in the correct order.
