# Seller contact data — SEPARATE FILE (by design)

**This file is intentionally empty of contact data.**

Rules that keep it that way:

1. Contact data (phone numbers, personal emails, private handles) is
   kept **separate from public signal data** (`SELLER_LIST_PUBLIC.md`)
   — this file is the only place it may ever live.
2. **Nothing was harvested.** Public captions were read for signal
   only; phone numbers visible in them were not copied anywhere in
   this repository (per `docs/SPRINT_BRIEF.md`: "do not copy masked or
   unmasked numbers into Hami").
3. An entry may appear here only when the **owner** supplies it (e.g. a
   warm introduction) or a seller gives it directly to the owner in a
   conversation the owner reports. Agent research never populates this
   file.
4. A public page or number is not consent to contact, access an
   account, or copy customer data.
