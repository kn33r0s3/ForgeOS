# Discovery loop — canonical operating spec

This file is subordinate to `AGENTS.md`, `docs/BRAIN.md`, current continuity records and explicit owner direction. If an older instruction here conflicts with those sources, follow the higher-priority current source. Hami's mission and breadth are settled; do not reopen the mission or gate Hami-wide progress on one seller, pilot or experiment.

## Purpose

Discover real-world value across domains and geographies: needs, knowledge gaps, resources, capabilities, coordination failures, overlooked connections, and ways to create, recover, preserve, protect or transform value. Revenue matters but does not define scope.

REALITY → OBSERVATION → EVIDENCE → UNDERSTANDING → UNKNOWN → QUESTION → CAPABILITY → AUTHORIZED ACTION → NEW REALITY.

The map and logs are a model, not the territory. Never manufacture people, leads, markets, events, evidence, revenue or outcomes. Preserve UNKNOWN. Keep REAL / TEST / MOCK / HYPOTHESIS distinct.

## Canonical model

Reuse only ENTITY, RELATION, EVENT, EVIDENCE, CAPABILITY and ACTION. Reuse existing Signal/Evidence, provenance, research, capability and action seams. No second architecture, duplicate ledger, extra primitive, redundant taxonomy, model/table or collector merely to represent a new topic.

## Each run

1. **Reconcile the repository.** Resolve exact main SHA and recent history. Read AGENTS.md, HANDOFF.md, STATE.md, QUEUE.md, docs/BRAIN.md, docs/UNKNOWN_MAP.md, docs/CAPABILITY_QUEUE.md, LOG.md, this file, relevant code/tests and available exact-head CI/security/deployment verification.
2. **Choose one evidence-rich slice, not one fixed domain.** One slice per run is a depth discipline, not a scope limit. Rotate across economic, social, public-service, infrastructure, knowledge, resource, security/privacy, scientific, environmental and technical systems as evidence warrants. Seller conversations and First Rupee are valid paths, not the center or a global gate.
3. **Establish source boundaries.** Separate public reporting, official records, firsthand evidence and model inference. Record exact scope, geography, publication/listing date, report/version, source-declared effective/observation cutoff, update time and retrieval time where available. Repeated reporting of one underlying source is one source family. Record contradictions without forcing resolution.
4. **Explain consequence.** Identify affected entities/relations, real-world consequence, resource/capability gap, existing Hami code seam and lawful next action. Do not call a coordination failure without direct evidence. Do not turn incomplete public reporting into emergency advice, a warning or alerting service.
5. **Respect source authorization.** Public visibility or browser access is not ingestion permission. Review each exact URL/operation/field against its own robots, terms, purpose, attribution, retention and redirects before collection/provider transmission. No blanket domain approval. If policies cannot be verified, keep NOT CLEARED. Do not send unreviewed source bodies to a provider.
6. **Respect action gates.** No external contact, data request, account use, publishing, money movement, spend, intake/outbound activation or consequential real-world action without explicit authorization.
7. **Bank one meaningful increment.** Update only existing continuity files that the finding changes: CAPABILITY_QUEUE, PUBLIC_SOURCES, UNKNOWN_MAP (only a genuinely new unknown; preserve parser/projection contract), LOG, STATE, QUEUE and HANDOFF. No filler or duplicate summaries. If a durable write is blocked, continue independent research/runtime/history checks and record the precise blocker.
8. **Protect main.** Never bypass a source-edit safety block through another tool. If code edits are blocked, use the authorized documentation path only. Group substantive changes into one commit; do not push while exact-head CI/deployment validation is still running unless an urgent safety fix requires it. After a write, verify the new exact head and report CI, security, deployment and health separately.
9. **Report honestly.** State established facts, reported/metadata-only claims, UNKNOWNs, capability gap, source-rights status, code seam, actions not taken and next lawful evidence step. A scheduled run is one observation, not proof of 24/7 execution.

## Evidence discipline

ACTUAL / OBSERVED / INFERRED / ESTIMATED / UNKNOWN must remain distinct. Online discourse is OBSERVED at best. A page date is not an effective-data cutoff; report number is not proof of newer facts; approval is not schedule; capacity is not delivered MWh; schedule is not settlement; LOI is not licence; licence is not completed transaction. Public evidence is not firsthand evidence.
